OpenRouter API 키는 서버 비밀값입니다. 여기에는 시연용 연결코드만 입력하세요. API 키를 넣지 마세요.

3단계로 시작하세요

  1. 확장 ZIP을 내려받고 압축 풀기
  2. Chrome 주소창에서 chrome://extensions → 개발자 모드 → 압축해제된 확장프로그램 로드 → extension 폴더 선택
  3. 이 페이지를 새로고침하고 목적 시작하기

이미 설치했다면 확장프로그램 새로고침 후 이 페이지도 새로고침하세요.

개인정보와 판단 기준

목적·도메인·제목만 서버와 OpenRouter 모델에 전달됩니다. 전체 URL의 경로·검색어, 본문, 비밀번호, 입력 폼은 보내지 않습니다. 제목에는 개인정보가 들어갈 수 있으므로 민감한 사이트에서는 AI를 끄세요.

AI 결과는 제목 기준 추정입니다. 0.8 이상인 ‘관련 없음’ 결과에만 경고합니다. 모델의 신뢰도 수치는 검증된 확률이 아닙니다. 허용·방해 목록이 우선이며, AI 실패 시 미등록 사이트는 미분류로 남깁니다. 모든 경고는 닫을 수 있어요.

통계는 확장프로그램 로컬에 저장됩니다. 브라우저 밖 앱·시선·실제 집중도는 측정하지 않습니다. Windows 알림 설정에 따라 시스템 알림이 보이지 않을 수 있습니다.
